✂️ 이모티콘 컷팅 메이커

이모티콘 시트를 올리면 12개로 잘라주고 배경까지 깔끔하게 지워드려요!

📱
핸드폰 사용자 필독! 삼성 인터넷 말고 크롬(Chrome)으로 열어주세요. 카톡 공유랑 이미지 저장이 잘 돼요!

🌟 처음 오셨나요? 따라하기만 하면 끝!

1

이미지 올리기

이모티콘이 모여있는 한 장짜리 이미지를 준비해요. 분홍색 박스를 누르거나 사진을 끌어다 놓으면 돼요.

📌 카카오 이모티콘 시트, 제미나이로 만든 그림 다 가능!

2

자르기 모드 선택

📐 격자 모드 — 가지런히 배치된 시트일 때 (12컷, 16컷, 9컷, 4컷, 20컷 모두 가능!)

🎯 자동 감지 — 제미나이처럼 글자랑 그림이 자유롭게 흩어진 이미지일 때

📌 격자 모드에서는 "⚡ 빠른 선택" 버튼으로 한 번에 4×3, 4×4 같은 배치를 고를 수 있어요!

3

이미지 크기 선택

📦 원본 크기 — 잘린 그대로 (보통 큼)

💬 카톡용 240px — 카카오톡 이모티콘 딱 좋은 크기 (추천!) ⭐

📱 중간 360px — SNS 프로필·약간 큰 용도

🖼️ 큼 500px — 고화질 보관용

✏️ 직접 입력 — 원하는 크기 자유 지정

📌 카톡에 보낼 거면 240px 선택! 화질 손상 없이 깔끔하게 줄여줘요.

4

자르기 시작 → 결과 확인

분홍색 "✨ 자르기 시작!" 버튼 누르면 12개로 잘라서 보여줘요. 마음에 안 들면 위쪽 설정 바꾸고 다시 누르면 됩니다.

📌 결과가 마음에 안 들면 위 설정 바꾸고 다시 누르면 돼요! 격자 안 맞으면 여백 조절, 자동 감지 이상하면 병합 거리 조절하세요.

5

저장하기 (3가지 방법)

① 갤러리에 저장 (제일 편해요!)
이미지를 꾹~ 길게 누르기 → "이미지 저장" 선택 → 갤러리에 들어가요!

② 카톡으로 바로 전송
파란색 📤 버튼 누르기 → 카카오톡 선택 → 친구 선택 → 끝!

③ 다운로드
분홍색 ⬇ 버튼 누르기 (크롬 다운로드 폴더에 저장됨)

📌 12개 한번에 받고 싶으면 맨 아래 "📦 전체 ZIP 다운로드"

❓ 자주 묻는 질문

Q. 이미지가 너무 커요. 카톡 이모티콘 크기로 줄여주세요

"이미지 크기"에서 "카톡용 240px"를 선택하세요! 화질 손상 없이 깔끔하게 축소돼요. 카톡 이모티콘으로 보내기에 240px가 딱 적당한 크기예요.

Q. 얼굴이 얼룩덜룩하게 잘렸어요

이 앱은 원본을 그대로 자르기만 하니까 얼룩이 생길 일이 없어요. 만약 그래 보인다면 원본 이미지 자체가 그런 거예요. 깃허브에 올린 새 버전인지 다시 확인하고 강제 새로고침(캐시 삭제) 해보세요.

Q. 다운로드한 파일을 못 찾겠어요 (핸드폰)

핸드폰은 다운로드 파일이 갤러리에 자동으로 안 들어가요. 이미지를 길게 눌러서 저장하거나 📤 공유 버튼을 사용하세요. 더 편해요!

Q. 자동 감지 모드가 이상하게 잘려요

설정값을 조절해보세요:
• 글자랑 그림이 따로따로 잘림 → "병합 거리" 늘리기 (50→100)
• 너무 묶여서 한 덩어리가 됨 → "병합 거리" 줄이기 (50→20)
• 작은 조각이 많이 잡힘 → "최소 크기" 늘리기 (80→150)
